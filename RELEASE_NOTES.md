# RE2 Annotated Map - Survivor's Notes 1.5.0

## English

- **Steam release support.** The mod now supports the Steam release as well as the GOG release. Copy the ZIP contents into the folder of the language you play (Steam: right-click the game > Manage > Browse local files).
- The mod recognizes the game by its map code instead of a specific executable. On an unsupported executable it patches nothing and only writes a log.
- Marker data comes from the GOG release. The Steam release, except Japanese, scripts a few rooms differently, so a marker in those rooms can differ from the game.
- Upgrading: close the game and extract the ZIP over the old files, keeping your `scripts/RE2.AnnotatedMap.ini`.

## 한국어

- **Steam판 지원.** GOG판에 더해 Steam판도 지원합니다. ZIP의 내용을 플레이하는 언어 폴더에 복사하세요(Steam: 게임 우클릭 > 관리 > 로컬 파일 보기).
- 특정 실행 파일 대신 지도 코드로 게임을 확인합니다. 지원하지 않는 실행 파일에서는 아무것도 패치하지 않고 로그만 남깁니다.
- 마커 자료는 GOG판 기준입니다. 일본어를 제외한 Steam판은 몇몇 방의 스크립트가 달라 그 방의 마커가 게임과 다를 수 있습니다.
- 업그레이드: 게임을 종료하고 ZIP을 기존 파일 위에 풀되, `scripts/RE2.AnnotatedMap.ini`는 유지하세요.
