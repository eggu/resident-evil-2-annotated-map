# 랭크와 설정

[한국어](12-rank-settings.md) | [English](12-rank-settings.en.md) · [Index](README.md)

랭크 예상치는 `[MapOverlay]`의 `Rank=1`로 켭니다. 저장 후 게임을 다시 실행하세요. 시간·저장 횟수·응급 스프레이 사용·무한 무기 플래그에 따라 계속 바뀌며 최종 결과를 보장하는 값은 아닙니다. 쉬움·보너스 모드에서는 표시하지 않습니다.

점수 = 시간 점수 + 저장 점수 + 스프레이 점수 − 무한 무기 감점(최저 0).

- 시간: 2시간 30분까지 100점, 이후 시작한 1시간마다 10점 감소, 최저 0점.
- 저장: 0–19회는 `100−5×횟수`, 20회부터 0점. 새 게임의 미설정 값은 0회로 취급합니다.
- 스프레이: 0–5회는 `100−15×횟수`, 6회부터 0점.
- 무한 무기 플래그가 설정되면 50점 감점합니다.

| 랭크 | 점수 |
| --- | --- |
| A | 269–300 |
| B | 199–268 |
| C | 144–198 |
| D | 99–143 |
| E | 0–98 |

## 설정

설정 파일은 `scripts/RE2.AnnotatedMap.ini`입니다. 게임 안에서 바꾼 값은 자동 저장됩니다. 이름 크기는 50–150%, 불투명도는 10–100%이며 10%씩 조절합니다. 확대하면 좁은 지도에서 이름이 겹칠 수 있습니다.
