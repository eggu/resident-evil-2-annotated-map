# Locked doors and keys

[한국어](04-locks-keys.md) | [English](04-locks-keys.en.md) · [Index](README.en.md)

Key icons mark doors that remain locked and are valid for the current scenario. `bank=255` selects the native door-unlock bit array; other values use the shared flag banks. Scenario mask 64 excludes A and Claire B; mask 128 excludes B. Down Key (93) is A-only; Up Key (94), Power Room Key (95), Master Key (98) and Platform Key (99) are B-only.
