# 원작 지도와 표시 범위

[한국어](01-native-map.md) | [English](01-native-map.en.md) · [Index](README.md)

표시 범위는 `8`로 방문한 방 → 공개된 방 → 모든 방 순서로 바꿉니다. 공개된 방은 층 지도 획득 여부와 방의 시나리오 마스크를 함께 적용합니다. 모든 방은 방 방문 제한을 해제하지만, 이미 주운 아이템이나 완료된 이벤트를 되돌려 표시하지 않습니다.

방 이름과 마커는 원작 지도 위에 덧그립니다. 남은 아이템이 있는 방에는 주황색을 더합니다. 이름·연결선의 불투명도는 아이콘·범례·랭크와 별도로 적용됩니다.

## 원작 데이터 참조

주소는 지원 대상 PC 실행 파일 기준입니다. 출력 해상도와 논리 지도 좌표는 별개입니다.

| 주소 | 내용 |
| --- | --- |
| `0x691f7a` | 현재 표시 지도 ID |
| `0x691fb8 / 0x691fba` | 지도 이동 x/y (signed short) |
| `0x98ec00` | 방문한 층 비트 |
| `0x98ec04` | 방 방문 비트 |
| `0x98ec1c` | 획득한 층 지도 비트 |
| `0x98ed2c` | 문 해제 비트 |
| `0x53eaf8 / 0x53eb98` | 레온/클레어 층 테이블 |
| `0x53b218` | SCD 플래그 bank 포인터 테이블 |
