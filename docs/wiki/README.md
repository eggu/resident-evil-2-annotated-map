## 표 읽는 법

- 지도 ID는 모드의 0–19번 지도 인덱스입니다. 게임의 층 이름이나 화면 해상도가 아닙니다.
- `seen`은 방 방문 플래그 번호이며, 방 코드와 별개입니다. 방 코드가 대응되지 않는 슬롯은 번호 그대로 표시합니다.
- 조건 `bank:bit=value`는 해당 플래그의 참/거짓 판정이며, `∧`로 연결한 조건은 모두 만족해야 합니다. 130/131번 bank는 각각 SCD 변수 0x1e/0x1f 비교이며, `130:n=1`은 변수 값이 n과 같음, `130:n=0`은 다름을 뜻합니다.
- 같은 위치도 시나리오·아이템·이벤트 조건에 따라 여러 행이 될 수 있습니다. 행 수는 고유 아이템 수나 동시 표시 수가 아닙니다.
- 좌표는 소스 데이터의 논리 지도 좌표입니다. 화면 이동·아이콘 중심 보정 전 값이며 PC 출력 픽셀과 다릅니다.
